<h1>RaphCare mobile update (v1.8.8+20)</h1>

Android patient app build **1.8.8** (install code **20**). File name: `RaphCare-v1.8.8+20.apk`. This build talks to the staging API, not a phone on localhost.

**Why this build:** clearer layout on Devices, Request a call, and Mental health so buttons stay on screen and the screens feel calmer.

## Updated

- **Devices and wearables:** card layout, clearer Scan / Claim / Connect actions, softer inputs.
- **Request a call:** Video, Audio, and Low data sit in one equal-width control so nothing is cut off.
- **Mental health:** mood choices in a two-by-two grid; PHQ-9 and GAD-7 stack full width.
- Version label **1.8.8** and install code **20**.

## Install

1. Uninstall any older RaphCare build if Android blocks the update.
2. Copy `RaphCare-v1.8.8+20.apk` to the phone (USB, Drive, or email).
3. Allow install from that source if Android asks.
4. Sign in as the demo patient: `demo.patient@raphcare.com` (password on the demo accounts sheet).

This is for sideload testing, not the Play Store.

## What to try

1. Sign in as the demo patient.
2. Open Devices and wearables. Check that Scan, Stop scan, and Claim fit the screen.
3. Open Request a call. Confirm Video, Audio, and Low data are all visible.
4. Open Mental health. Confirm mood buttons and Start PHQ-9 / Start GAD-7 are fully on screen.
