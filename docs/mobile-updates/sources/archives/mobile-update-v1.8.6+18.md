<h1>RaphCare mobile update (v1.8.6+18)</h1>

Android patient app build **1.8.6** (install code **18**). File name: `RaphCare-v1.8.6+18.apk`. This build talks to the staging API, not a phone on localhost.

**Why this build:** a calmer, more polished look on the main screens you open first, without changing how features work.

## Updated

- Softer page background, larger rounded cards, and gentler shadows across shared buttons, fields, and cards.
- Landing, Sign in, Home, and Profile look more open and premium while the same taps and flows still work.
- Version label **1.8.6** and install code **18**.

## Install

1. Uninstall any older RaphCare build if Android blocks the update.
2. Copy `RaphCare-v1.8.6+18.apk` to the phone (USB, Drive, or email).
3. Allow install from that source if Android asks.
4. Sign in as the demo patient: `demo.patient@raphcare.com` (password on the demo accounts sheet).

This is for sideload testing, not the Play Store.

## What to try

1. Open the welcome screen: check the logo card, Sign in, and Create account.
2. Sign in: confirm the form spacing and the teal Sign in button still work.
3. Open Home: greeting, Request a call card, upcoming visit, quick actions, and health cards.
4. Open Profile: photo, menu rows, and Sign out still behave the same.
