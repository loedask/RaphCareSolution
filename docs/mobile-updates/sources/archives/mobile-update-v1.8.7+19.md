<h1>RaphCare mobile update (v1.8.7+19)</h1>
</div>

Android patient app build **1.8.7** (install code **19**). File name: `RaphCare-v1.8.7+19.apk`. This build talks to the staging API, not a phone on localhost.

**Why this build:** claim an assigned watch by photographing the packaging barcode or QR, not only by typing the serial.

## Added

- On Devices and wearables, **Photo of barcode** fills the claim serial from a clear packaging barcode or QR (then tap Claim watch).

## Updated

- Claim hint explains photo or typed serial.
- Version label **1.8.7** and install code **19**.

## Install

1. Uninstall any older RaphCare build if Android blocks the update.
2. Copy `RaphCare-v1.8.7+19.apk` to the phone (USB, Drive, or email).
3. Allow install from that source if Android asks.
4. Sign in as the demo patient: `demo.patient@raphcare.com` (password on the demo accounts sheet).

This is for sideload testing, not the Play Store.

## What to try

1. Sign in as the demo patient.
2. Open Devices and wearables.
3. Tap **Photo of barcode**, photograph the packaging code for an assigned watch, confirm the serial field fills, then Claim watch.
4. You can still type the serial if the photo does not read cleanly.
