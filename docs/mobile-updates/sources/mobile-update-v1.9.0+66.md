Android patient app build **1.9.0** (install code **66**). File name: `RaphCare-v1.9.0+66.apk`. This build talks to the staging API, not a phone on localhost.

**Why this build:** Preview checkpoint for the commercial wave (Practice plan, consult waiting display, pricing, and payments work that follows). This is **not** the daily stable Connect APK. Keep using your last good Connect build for watch tests until we say otherwise.

## Added

- Version label **1.9.0** and install code **66** as the commercial-wave preview marker.

## Updated

- Same Connect path as 1.8.53 for now (mac-only overload and warm scan). No new watch fix in this preview alone.

## Install

1. Uninstall any older RaphCare build if Android blocks the update.
2. Copy `RaphCare-v1.9.0+66.apk` to the phone.
3. Force-stop the separate **H Band** app if it is installed.
4. Sign in as the demo patient.

## What to try

1. Sign in and open Home to confirm the build label.
2. For watch Connect diagnostics, prefer your last known-good Connect APK unless you are specifically testing this preview.
